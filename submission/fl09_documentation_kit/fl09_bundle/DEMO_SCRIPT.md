# Demo Script — 3-5 Minutes, Live Run, No Slides

Record your actual screen running the actual app. This is a script to keep you on time and on
point, not something to read verbatim — sound like yourself.

## Before you hit record

- [ ] App running locally or the live URL open, ready to go — no dead air setting up on camera.
- [ ] One test scenario prepared that you know works cleanly.
- [ ] One scenario prepared that shows the limitation you're going to name.
- [ ] Screen recorder + mic tested (a 10-second test clip, check audio isn't clipping).

## Structure (aim for ~4 minutes)

**0:00–0:30 — What this is and who it's for**
Say it in one breath, the way you'd explain it to a friend: "[App name] is [what it does] for
[who]. The problem I was solving was [the actual pain point]."

**0:30–2:30 — Live walkthrough**
Actually use the app, narrating as you go. Don't explain code you're not showing — show the thing
running and talk about what's happening and why.
- [Step 1 — the entry point: what does a user see first]
- [Step 2 — the core action: the thing the app is actually for]
- [Step 3 — the result: what comes back, what changed]

**2:30–3:15 — One design decision, explained**
Pick one real choice and say why: "I decided to [do X] instead of [the more obvious Y] because
[the actual reason — a constraint, a tradeoff, something you learned]." This is the part that
shows judgment, not just output — don't skip it or rush it.

**3:15–4:00 — One limitation, on camera**
Show it happening if you can (don't just describe it — trigger the actual failure or edge case).
"Here's something that doesn't work yet: [show it]. That's because [real reason]. If I kept
building, the next thing I'd fix is [specific next step]."

**4:00–4:30 — Close**
"That's [app name] — built with [AI tool] for [what part], and [what you personally checked /
drove]. Repo's linked below."

## Reminders

- Live run, not slides — if you catch yourself about to switch to a deck, stop and go back to the
  running app.
- 3-5 minutes total — practice once with a timer before the real take.
- The limitation segment is not optional and not a throwaway line — it's graded criteria.
