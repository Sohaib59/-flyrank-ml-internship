# FL-09 / FL-10 Final Checklist

## Assignment 8.1 — Documentation and demo

- [ ] `README.md` — every `[bracket]` replaced with real content, no placeholders left.
- [ ] Setup section tested by literally following your own steps from a clean clone/checkout.
- [ ] Eval results are real numbers you actually measured — not invented, and not silently
      dropped if you don't have formal ones (say so honestly instead).
- [ ] Limitations list is real and specific — not "could be more scalable."
- [ ] AI-transparency line names the actual tool and the actual split of what it did vs. what
      you did/checked.
- [ ] Demo recorded: live run, no slides, 3-5 minutes, one design decision + one limitation
      shown on camera.
- [ ] README and demo video link posted to the showcase thread.

## Assignment 8.2 — Final package, retrospective, capstone

- [ ] One repo or shared folder with an index page/README linking every deliverable from the
      whole track.
- [ ] Retrospective: 500-800 words, specific to your actual build (use the scaffold, not the
      generic version).
- [ ] Hours log completed in the portal, plausible against your actual timestamps.
- [ ] Personal site published live on the FlyRank domain, navigable in five minutes.
- [ ] Build-in-public post published, explaining one real decision and one real limitation.
- [ ] Submitted for the final review checkpoint.
